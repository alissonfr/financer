# finance

Monorepo com o frontend e a API do finance.

| Pasta | Stack |
| --- | --- |
| [finance-angular](finance-angular) | Angular 19 |
| [finance-nestjs](finance-nestjs) | NestJS 10 + Postgres |

```bash
npm run install:all   # instala dependências dos dois projetos
npm run db:up         # sobe o Postgres
npm run dev:api       # API em modo watch
npm run dev:web       # frontend
```
